# Refactorización y Code Smells

Material de práctica del módulo "bonus" de Refactorización y Code Smells
(FDS 4, viernes — si sobra tiempo tras resolver dudas del proyecto).

## Contenido

- **`code_smells.ipynb`** — recorre los 13 code smells más comunes
  cubiertos en el deck de la sesión (`05_Refactoring_CodeSmells.pptx`),
  organizados en las 5 categorías estándar de refactoring.guru:
  **Bloaters**, **Object-Orientation Abusers**, **Change Preventers**,
  **Dispensables** y **Couplers**. Por cada smell: definición, síntoma,
  código "con el smell", código refactorizado y la técnica de refactor
  aplicada. Cierra con ejercicios prácticos y autoevaluación.

## Cómo usarlo

Igual que los notebooks de `patrones/` y `solid/`: ábrelo en Jupyter y
ejecuta las celdas en orden. Cada bloque de código está pensado para
correr de forma independiente (cada smell define sus propias clases),
así que también puedes saltar directamente a la sección que te interese.

## Conexión con la evaluación

El ejercicio 5 del notebook — diagnosticar los code smells de tu propio
proyecto — es exactamente lo que pide el diagnóstico del "antes" en la
**Actividad 4** (proyecto integrador, 60 de 350 pts). Ver
`docs/rubricas/proyecto.md` para la rúbrica completa.
